# Cross-Agent Workflow

This directory documents UniProof host routing. It does not duplicate global agents or skills.

## Session Entry Points

- Codex and compatible agents: read root `AGENTS.md`; the first manual project read remains `LESSONS.md`.
- Claude Code: read root `CLAUDE.md`, then the canonical root instructions.
- Any host: read `AGENT_MEMORY.md` after `LESSONS.md` and verify changing facts from the live workspace.

## Global Specialist Routing

Global Codex agents live in `C:\Users\LOQ\.codex\agents`.

- `ui-designer`: frontend design and React/Next.js implementation.
- `api-designer`: read-only API contract design.
- `backend-developer`: server/API implementation.
- `data-engineer`: research ingestion, normalization, and provenance pipelines.
- `typescript-pro`: TypeScript contract and compiler-focused work.
- `test-automator`: automated regression coverage.
- `code-reviewer`: read-only code-quality review.
- `security-auditor`: read-only security review.
- `docs-researcher`: primary-source documentation research.
- `requirements-traceability`: requirement/evidence coverage audit.
