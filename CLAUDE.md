# Claude Code Entry Point

The canonical cross-agent instructions are in `AGENTS.md`.

At the start of every session:

1. Read `LESSONS.md` first as the first manual project read.
2. Read `AGENT_MEMORY.md` and verify mutable facts against the live workspace.
3. Follow `AGENTS.md` and the active task-specific requirements or plan.

For current closure, local cleanup, and hosted-provider evidence, consult [`docs/operations/project-closure.md`](docs/operations/project-closure.md). Treat dated deployment/submission plans as historical; do not recreate hosted resources without a new explicit owner request.

Do not duplicate project rules here. Update `AGENTS.md` when shared instructions change.
